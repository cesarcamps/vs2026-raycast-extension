Visual Studio 2026 Recent Projects — una extensión de Raycast para Windows que muestra el historial de proyectos y soluciones recientes de Visual Studio. Importa el MRU desde `ApplicationPrivateSettings.xml`, el registro de Windows, y escanea carpetas de desarrollo en busca de archivos `.sln`. Incluye ranking híbrido por frecuencia de uso y recencia, proyectos anclados (pinned), búsqueda fuzzy, filtro por tags y por días de uso, y apertura directa con VS Stable/Preview/Enterprise.
